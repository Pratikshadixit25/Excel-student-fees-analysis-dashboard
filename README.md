# Excel Student Fees Analysis Dashboard

## Project Overview

The Student Fees Analysis Dashboard is an interactive Excel dashboard designed to analyze student fee collection, outstanding fees, and course-wise fee performance.

This project uses Excel Tables, formulas, PivotTables, PivotCharts, KPI cards, and slicers to transform student fee data into meaningful insights that support better fee monitoring and decision-making.

## Project Objectives

- Analyze total student fees and fee collection.
- Track collected and outstanding fees.
- Compare outstanding fees across different courses and branches.
- Identify areas that may require more fee follow-up.
- Build an interactive dashboard for exploring fee-related data.

## Tools and Features

- Microsoft Excel
- Excel Tables and structured references
- Excel formulas and KPI cards
- PivotTables and PivotCharts
- Doughnut Chart for collected versus pending fees
- Interactive slicers for Branch, Course, and Fee Status
- Data visualization and business insights

## Key Performance Indicators

The dashboard includes the following KPIs:

- Total Students
- Total Fees
- Fees Collected
- Outstanding Fees

## Dashboard Analysis

The dashboard helps analyze:

- Total fees collected versus pending fees
- Course-wise outstanding fees
- Branch-wise fee collection and outstanding amounts
- Fee status distribution
- Fee performance across different categories

## Interactive Features

Users can filter dashboard results using slicers.

- Branch: Analyze data for selected branches.
- Course: Explore fee data by course.
- Fee Status: Filter students according to their fee status.

The dashboard updates based on the selected filters.

## Key Insights

Based on the current dataset:

- Total Students: 100
- Total Fees: Rs. 35,68,000
- Fees Collected: Rs. 22,55,000
- Outstanding Fees: Rs. 13,13,000
- Approximately 63% of the total fees have been collected, while 37% remain outstanding.
